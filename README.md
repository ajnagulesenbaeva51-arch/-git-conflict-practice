1. Почему не коммитят venv?
Она слишком много весит (тысячи файлов) и привязана к конкретной операционной системе — на другом компьютере она всё равно не заработает.
2. Что будет без venv и как восстановить?
Код выдаст ошибку ModuleNotFoundError (не найдены библиотеки). Для восстановления нужно создать новое окружение (python -m venv venv), активировать его и выполнить pip install -r requirements.txt.
3. Зачем нужен requirements.txt и как связан с .gitignore?
Это легкий текстовый список нужных библиотек и их версий. В .gitignore добавляют саму папку venv/ (чтобы не загружать её), а requirements.txt оставляют открытым для Git — он заменяет собой папку окружения при переносе проекта.
